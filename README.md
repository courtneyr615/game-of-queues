# Game of Queues - simultaneous multiplayer

Open **START HERE - Render.md** for setup and rules. This is a separate server app for Game of Queues; do not upload it over the Game of Life / ASNF repository.

- Four players can roll, move, investigate, and accuse independently.
- Every player's first correct accusation in each room earns 50 points.
- The room's first solver gets an extra 25 points, once.
- Private clues, notes and patient bonus responses are stored separately for each player.

Run `npm test` to validate, then `npm start` to serve the game.
